# API 接口设计规范 v1.3

适用范围：本团队所有对内服务。网关统一前缀 `/api/v1`。

## 通用约定

- 所有接口使用 HTTPS + JSON；
- 字段命名使用小驼峰；时间统一 ISO8601 带时区；
- 列表接口分页参数 `page` / `pageSize`，默认 20，最大 100。

## 认证

采用 Bearer Token。内部服务走服务账号 + 短期凭证（有效期 2 小时），外部调用走 OAuth2 授权码模式。**禁止在 URL 与日志中出现明文凭证**。

## 错误码

| code | 含义 | 处理建议 |
| --- | --- | --- |
| 0 | 成功 | - |
| 40001 | 参数校验失败 | 检查请求体 |
| 40101 | 未认证 | 重新获取 token |
| 40301 | 无权限 | 申请对应资源权限 |
| 42901 | 触发限流 | 指数退避重试 |
| 50001 | 服务内部错误 | 联系服务 Owner |

## 幂等与重试

写操作必须携带 `X-Idempotency-Key` 请求头；客户端对 5xx 与 429 做指数退避重试，最多重试 3 次。

## 示例

```json
POST /api/v1/reports
{ "templateId": "weekly", "dateRange": ["2026-09-08", "2026-09-12"] }
```
