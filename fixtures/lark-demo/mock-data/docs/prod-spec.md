# 产品需求文档：智能周报生成器

> 文档编号 PRD-2026-018 · 负责人：李明 · 状态：评审中
> 最近更新：2026-09-10

## 一、背景与目标

团队成员每周五花 30-60 分钟手写周报，格式不统一，信息重复度高。本项目目标是在飞书内一键生成结构化周报草稿，预期将平均撰写时间降至 5 分钟以内。

北极星指标：**周报撰写人均耗时下降 80%**。

## 二、核心功能

### 2.1 自动汇总

自动读取用户本周在飞书的日程、任务、文档编辑记录，生成周报初稿，用户只需微调确认。

### 2.2 多模板

支持「个人周报」「团队周报」「管理者视角」三种模板，可由管理员在后台配置字段与顺序。

### 2.3 定时提醒

每周五 16:00 通过飞书机器人推送提醒卡片，点击卡片直接进入生成页面。

### 2.4 敏感信息过滤

生成前对内容做脱敏扫描，命中规则（手机号、身份证号、API 密钥）时自动遮蔽并提示用户确认。

## 三、非功能需求

- **性能**：生成耗时 P95 < 8s；
- **可用性**：服务可用性 ≥ 99.9%；
- **合规**：所有数据仅存储在租户内，不出域；
- **权限**：仅读取用户授权范围内的数据，需用户显式 OAuth 授权。
