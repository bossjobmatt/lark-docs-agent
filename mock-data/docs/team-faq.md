# 团队 FAQ 与上线流程

## 上线流程

1. **提测**：代码合并至 release 分支，CI 全绿；
2. **预发验证**：产品 + 测试在预发环境验收，填写验收单；
3. **上线申请**：在运维平台提交工单，注明变更范围与回滚预案；
4. **灰度**：按 5% → 50% → 100% 分三批放量，每批观察 30 分钟；
5. **复盘**：上线后 24 小时内同步核心指标。

回滚预案必须包含：回滚命令、数据兼容性说明、负责人电话。

## 常见问题

### Q：测试环境账号怎么申请？

A：在「权限助手」机器人中发送 `/apply 测试环境`，导师审批后自动开通。

### Q：周报模板在哪里修改？

A：管理员后台 → 模板管理，支持自定义字段；改动对下周一生效。

### Q：如何申请第三方数据接入？

A：填写《数据接入申请表》并 @数据平台值班人，SLA 为 2 个工作日。

### Q：线上问题怎么上报？

A：P0/P1 直接电话联系值班（见值班表），P2 及以下在 Lark 群「线上问题同步」发帖。
